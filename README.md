# BandWagon

BandWagon은 젤 전기영동(gel electrophoresis) 이미지에서 레인과 밴드를
검출하고, 분자량(MW)을 계산하며, 분석 결과를 이미지와 CSV로 내보내는
데스크톱 분석 도구입니다. 가시광 이미지와 UV 이미지를 정렬해 합성하는
웨스턴 블롯 작업도 함께 지원합니다.

최신 Windows 설치본과 포터블 버전은
[GitHub Releases](https://github.com/loselessss/BandWagon/releases/latest)에서
받을 수 있습니다.

## 만든 이유

젤 이미지를 분석하려면 이미지 방향과 기울기를 바로잡고, 레인 범위를 정한
뒤, 밴드 위치와 강도를 읽고, 마커를 기준으로 분자량 곡선을 맞춰야 합니다.
이 과정을 여러 프로그램과 수작업으로 나누면 같은 조건으로 다시 분석하기
어렵고 결과를 재현하기도 번거롭습니다.

BandWagon은 이 흐름을 한곳에 모읍니다.

- 젤 이미지의 방향, 기울기, 곡률, 원근을 보정합니다.
- 레인을 자동 검출하거나 직접 추가하고 범위를 조정합니다.
- 밴드를 검출하고 피크 면적과 상대 강도를 계산합니다.
- 분자량 마커를 바탕으로 MW 보정 곡선을 맞춥니다.
- 이미지, 레인, 보정값, 분석 설정과 메모를 프로젝트 하나에 저장합니다.
- 가시광·UV 채널을 별도 스튜디오에서 정렬하고 합성합니다.

## 주요 기능

### 이미지 보정

- 90도 회전, 좌우·상하 반전
- 정밀 회전과 기울기(shear) 보정
- 휘어진 젤의 곡률 보정
- 네 모서리 지정 원근 보정과 자동 펴기
- 밝기, 대비, 채널별 톤 커브 조정
- RGB 및 개별 Red·Green·Blue 채널 분석

### 레인과 밴드 분석

- 레인 자동 검출 및 수동 추가·삭제·정렬
- 레인 이름, 유형, 표시 순서 관리
- 분석 범위와 최소 밴드 간격 조정
- 밴드 민감도와 스미어 허용 범위 조정
- 밴드 경계 영역 또는 피크 선 표시
- 피크 면적, 상대 강도와 분자량 결과 표 제공

### 분자량 보정

- 마커 레인과 기준 분자량 입력
- 사용자 마커 프리셋 저장 및 재사용
- 분자량 커브 피팅과 미지 밴드 MW 계산

### 웨스턴 블롯 합성

- 가시광 이미지와 UV 이미지 불러오기
- 두 채널의 위치·회전·크기 정렬
- 화면용 합성 이미지와 분석용 UV 그레이스케일을 함께 보존
- `.bwcomposite` 파일로 내보낸 뒤 메인 분석 화면에서 불러오기

### 작업 보존과 내보내기

- 이미지와 모든 분석 상태를 `.bandwagon` 프로젝트 하나로 저장
- 이미지·레인·분석 설정·메모를 포함한 최대 200단계 실행 취소/다시 실행
- 사진 포함 여부와 테두리·Marker MW·레인 MW·Annotation(레인 이름)을 선택해 이미지 저장 또는 복사
- 글자와 그림·테두리 투명도, 투명 배경 미리보기, 마지막 내보내기 옵션 기억
- 레인·밴드 결과 CSV 내보내기
- 한국어·영어 UI

## 설치

[최신 릴리스](https://github.com/loselessss/BandWagon/releases/latest)에서
사용 방식에 맞는 파일을 받으세요.

- `BandWagon_Setup_<version>.exe`: 시작 메뉴, 바탕화면 바로가기와 제거
  기능을 제공하는 Windows 설치본
- `BandWagon_Portable_<version>.zip`: 압축을 푼 폴더에서 바로 실행하는
  포터블 버전

설치본과 포터블 모두 앱 안에서 새 버전을 확인할 수 있습니다. 설치본은 다음
Setup EXE를 받고, 포터블은 다음 Portable ZIP을 받아 기존 폴더를 교체합니다.
포터블 교체 후 새 버전이 정상적으로 시작하지 못하면 이전 폴더를 복구합니다.

## 사용법

아래 안내는 현재 소스의 UI를 기준으로 합니다. 이전 배포본은 버튼 위치나 동작이 다를 수 있습니다.

기본 순서는 **이미지 열기 → 회전 → 자르기·펴기 → 레인 지정 → 밴드 검출 → 마커 설정 → MW 결과 → 저장**입니다.

상단의 **파일·보정·레인·웨스턴블롯·정보**에서 작업을 고르고, 가로 리본의 아이콘을 누르세요.
새 분석 창은 **파일** 리본부터 표시합니다.
오른쪽 설정이 바뀌어도 메인 이미지 미리보기는 유지됩니다. 버튼 설명은 마우스를 올리면 나타납니다.
리본이 창 너비를 넘으면 좌우 화살표로 나머지 아이콘을 볼 수 있습니다. 언어 선택은 **정보**에 있습니다.

### 1. 이미지 열기와 방향 맞추기

1. **파일**에서 이미지를 열거나 클립보드 이미지를 붙여넣습니다.
2. **보정 → 회전**에서 레인이 세로로 서고 밴드가 가로로 놓이도록 먼저 방향을 맞춥니다.
3. 필요하면 정밀 회전으로 기울어진 사진을 맞추고, **뒤집기**로 좌우·상하 방향을 바꿉니다.

이미지는 드래그로 이동하고 휠로 확대할 수 있습니다. 먼저 방향을 맞춘 뒤 영역을 자르고 레인을 지정하세요.
레인을 지정한 뒤 기하 보정을 하면 레인 위치나 검출 결과를 다시 확인해야 합니다.

### 2. 젤 영역 자르기와 보정

- **자르기:** 남길 사각 영역을 이미지에서 드래그하고 Enter 또는 **자르기 적용**을 누릅니다.
  젤 밖의 배경과 불필요한 좌우 여백을 줄이되, 필요한 밴드와 마커는 남기세요. 자르기는 원근을 바꾸지 않습니다.
- **펴기:** 자동으로 젤 영역을 찾거나 네 모서리를 직접 지정해 원근을 보정합니다.
  자동 인식한 모서리가 젤 테두리와 맞는지 확인하고, 필요하면 드래그해 수정한 뒤 적용하세요.
- **기울기:** 레인이 한쪽으로 기운 경우 shear 보정을 조절합니다.
- **곡률:** 휘어진 기준 밴드를 따라 곡률을 조절합니다. 기준선 방식은 아래를 참고하세요.
- **밝기·대비 / 톤 커브:** 사진을 보기 좋게 조절합니다. 이 색상 보정은 화면 표시용이며 분석값은 바꾸지 않습니다.
- **색상 반전:** 아이콘을 누르면 별도 설정 화면 없이 즉시 적용됩니다. 다시 누르면 원래 색으로 돌아옵니다.
  표시용 밝기 보정과 달리 분석 원본도 바뀌므로 밴드 검출에 영향을 줍니다.

가이드는 기하 보정 도구에서 표시합니다. 도구를 바꾸면 미확정 보정을 적용해 유지하므로,
취소하려면 전환 전에 Esc 또는 Ctrl+Z를 사용하세요.

#### 기준선으로 곡률 펴기

1. **곡률** 설정에서 **곡률 펴기**를 누릅니다. 별도 창 대신 메인 이미지에 보라색 기준선과 손잡이 5개가 나타납니다.
2. 같은 높이로 펴고 싶은 밴드를 따라 손잡이를 맞춥니다. 결과는 드래그 중 미리보기에서 갱신됩니다.
   중간 손잡이는 좌우로도 움직일 수 있습니다.
3. 선 전체를 옮길 때는 왼쪽 작은 위아래 화살표 손잡이를 사용합니다. 기존 곡률 모양과 이미지 보정량을 유지한 채 기준선만 이동합니다.
4. 이미지 아래 도구 모음에서 원본 비교·초기화·화면 맞춤을 사용하고, **적용**으로 확정합니다.
   눈 아이콘을 누르고 있으면 원본을 비교할 수 있고, Esc 또는 Ctrl+Z는 미확정 작업을 취소합니다.

자동 펴기에서 `펴기 후 곡률 손잡이 표시`를 선택하면 곧바로 기준선을 조절할 수 있습니다.
이 보정은 이미지의 각 열을 같은 양만큼 세로로 이동합니다. 위·아래에서 곡률이 서로 다른 사진까지
자동으로 맞추는 기능은 아니므로, 기준 밴드뿐 아니라 다른 높이의 밴드도 확인하세요.

### 3. 레인 지정

1. **레인 → 자동 검출**에서 실제 레인 수를 입력하고 **레인 자동 검출**을 누릅니다.
   마커 레인도 개수에 포함하세요. 완료되면 밴드 검출도 자동으로 실행됩니다.
2. 이미지 위 경계가 각 레인을 올바르게 나누는지 확인합니다. 경계가 빗나가면 드래그로 폭을 수정합니다.
3. 직접 추가하려면 **수동 조정**을 켜고 이미지에서 레인 폭을 좌우로 드래그합니다. 같은 패널 아래에서 밴드 검출 조건을 조절하고 **밴드 검출**을 실행할 수 있습니다. 이름·유형·순서는 **레인 목록**에서 관리합니다.
4. **레인 목록**에서 이름·유형·순서와 삭제를 관리합니다.

자동 검출은 입력한 개수를 기준으로 균등 간격 주변의 빈 공간을 찾는 방식입니다.
젤 밖의 여백이 많거나 레인 간격이 불규칙하면 틀릴 수 있으며, 균등 경계에서 이동하는 범위는 ±15%로 제한됩니다.
웰이나 염료 전선을 제외하려면 **세로 범위**를 지정하세요. 지정한 범위는 레인 자동 검출과 밴드 검출에 사용됩니다.

레인 이름 입력 후 Enter/Tab을 누르면 다음 이름 칸을 편집합니다. Shift+Tab은 이전 칸, Esc는 입력 취소입니다.
레인 경계나 분석 범위를 바꿨다면 **밴드 검출**을 다시 실행하세요.

### 4. 밴드 검출과 확인

**레인 → 수동 조정**에서 조건을 조절하고 설정 아래쪽의 **밴드 검출** 버튼을 누릅니다. 별도의 검출 설정 리본 버튼은 없으며 수동 조정에서 함께 관리합니다.
조건을 바꾸는 동안 실시간으로 재검출하지 않으며, 실행 버튼은 리본에 중복 배치하지 않습니다.
자동 레인 검출 직후에는 이미 밴드를 검출했으므로, 조건을 바꾸지 않았다면 반복 실행할 필요가 없습니다.
같은 조건으로 다시 누르면 결과도 같습니다. 버튼 설명은 마우스오버로 확인할 수 있고,
검출 완료와 밴드 개수는 맨 아래 상태줄에만 표시됩니다. 재검출 후에는 미리보기 테두리가 짧게 강조되어 갱신을 알려줍니다. 실행 횟수는 표시하지 않습니다.

- **민감도:** 높이면 더 약한 밴드까지 검출합니다. 배경을 밴드로 잡으면 낮추고, 약한 밴드를 놓치면 높여보세요.
- **최소 밴드 간격:** 가까운 피크를 서로 다른 밴드로 잡을 때 사용하는 최소 세로 간격입니다.
- **경계 임계값:** 밴드 위·아래 경계를 정합니다. 높이면 영역이 좁아지며 정량값도 바뀝니다.
- **최대 밴드 길이:** 지정한 세로 길이(px)보다 큰 밴드를 결과에서 제외합니다. 0은 이 추가 제한을 끕니다.

검출은 세로 배경 변화와 넓은 번짐을 분리한 신호를 사용합니다. 최대 밴드 길이를 0으로 두어도
이 배경 분리는 동작합니다. 정량은 검출 경계 안의 원본 강도를 국소 배경 차감 후 적분합니다.
자동 결과는 정답이 아니며, 아주 넓은 실제 밴드의 누락이나 배경 오검출이 있을 수 있습니다.
마커를 지정하기 전에 밴드 위치와 경계를 먼저 확인하세요.

밴드를 이미지에서 클릭하면 결과 표의 해당 강도 칸으로 이동합니다. 조건 변경 후 재분석 안내가 나오면
다시 검출하세요. 화면의 밴드 표시를 영역 또는 피크 선으로 바꾸는 것은 정량값에 영향을 주지 않습니다.
**MW 결과**에서는 레인 이름이나 밴드가 없는 레인 내부를 클릭하면 해당 샘플의 첫 결과 행으로 이동합니다.
샘플·밴드·MW·강도·Volume 다섯 열은 표 너비에 맞춰 자동 배분합니다. MW 단위는 제목의 툴팁으로,
긴 샘플 이름이나 숫자의 전체 내용은 셀의 툴팁으로 확인할 수 있습니다.

### 5. 마커 설정과 MW 확인

1. **레인 → 마커 설정**에서 사용할 마커 **프리셋을 먼저 선택**합니다. 직접 값을 넣으려면 **직접 입력**을 고릅니다.
2. **적용할 레인**에서 사진의 마커 레인을 선택합니다. 선택한 레인이 미리보기에서 강조됩니다.
3. **마커 지정**을 누릅니다. 검출이 필요하면 먼저 밴드를 검출합니다.
4. 프리셋과 밴드 개수가 같으면 위에서 아래 순서로 MW를 바로 적용합니다. 별도 입력창은 열리지 않습니다.
   개수가 다르면 밴드별 대응을 확인하는 창이 열립니다. 기준점에서 제외할 밴드는 0 또는 `—`로 설정하세요.
   적용 후 미리보기에서 밴드와 기준 MW의 대응을 확인하세요. 프리셋의 MW 값은 **마커 프리셋**에서 편집합니다.
5. 서로 다른 위치의 유효한 기준점이 2개 이상이면 MW를 계산하고 **MW 결과**로 이동합니다.
   기준점이 부족하면 마커 설정 화면에서 입력을 보완하세요. 취소하면 원래 레인 유형을 유지합니다.

레인 목록의 유형을 **마커**로 바꿔 입력창을 여는 방법도 사용할 수 있습니다.
프리셋 추가·삭제·가져오기·내보내기는 레인 리본 맨 뒤의 **마커 프리셋**에서 관리합니다.
마커 범위 밖의 밴드는 범위 끝값으로 제한되므로, 표시된 MW를 정확한 외삽값으로 해석하지 마세요.

정량이 필요하면 알려진 양을 가진 레인 2개 이상을 **BSA** 유형으로 지정하고 기준량을 입력한 뒤
**정량**에서 표준 곡선과 시료 추정량을 확인합니다. 메모는 **파일 → 메모**에서 작성합니다.

### 6. 프로젝트 저장과 결과 내보내기

- **파일 → 프로젝트 저장:** `.bandwagon`으로 저장해 편집과 분석을 나중에 이어갑니다. Ctrl+S로 저장할 수 있습니다.
- **파일 → CSV 내보내기:** 레인별 밴드 결과를 표 파일로 내보냅니다.
- **파일 → 결과 이미지 복사 / 결과 이미지 저장:** 같은 옵션 창에서 출력 요소를 고릅니다.

복사·저장 옵션에서 `사진 포함`, `테두리`, `밴드 범위`, `Marker MW`, `레인 MW (일반·BSA)`, `Annotation(레인 이름)`을 선택합니다.
`사진 포함`을 끄면 선택한 요소만 투명 오버레이로 출력됩니다. `레인 MW`는 기본으로 꺼져 있으며,
켜면 일반·BSA 레인의 계산된 MW도 포함합니다. 마커 MW와 독립적으로 선택할 수 있습니다.
`밴드 범위`도 기본으로 꺼져 있으며, 켜면 화면에서 선택한 영역 박스(채우기 포함) 또는 피크 선 방식으로 출력합니다.

`글자 투명도`는 레인 이름과 모든 MW 글자에, `그림·테두리 투명도`는 사진·테두리·밴드 범위에 적용됩니다.
`투명도 함께 조절`을 끄면 각각 설정할 수 있습니다. 0%는 불투명, 100%는 완전 투명입니다.
체크무늬는 투명 영역을 뜻하며 실제 출력은 원본 해상도입니다. 마지막으로 확정한 옵션은 다음에도 유지됩니다.

Ctrl+Z로 되돌리고 **정보 → 다시하기** 또는 Ctrl+Y로 복원할 수 있습니다. Ctrl+W는 현재 분석 창만 닫으며,
저장하지 않은 변경사항이 있으면 저장 여부를 확인합니다.

### 가시광·UV 이미지 합성

1. **웨스턴블롯 → 만들기**를 열고 가시광 사진과 UV 사진을 불러옵니다.
2. 스튜디오 리본의 **정렬**에서 두 사진의 위치·회전·크기를 맞춥니다.
3. **합성 설정**에서 미리보기를 확인하고 **내보내기**로 `.bwcomposite` 파일을 저장합니다.
4. 메인 화면의 **웨스턴블롯 → 기존 합성 파일 불러오기**로 합성 파일을 불러온 뒤 위의 레인·밴드 분석을 진행합니다.

합성 파일은 화면용 이미지와 분석용 UV 신호를 함께 보존합니다.

## 파일 형식

- `.bandwagon`: 원본 이미지, 편집 기록, 레인, 분석 설정, 분자량 보정과
  메모를 담는 BandWagon 프로젝트
- `.bwcomposite`: 화면용 합성 PNG와 분석용 UV 그레이스케일 PNG를 함께
  담는 웨스턴 블롯 합성 파일

두 형식 모두 다른 프로그램의 임시 상태에 의존하지 않고 나중에 다시 열어
분석을 이어갈 수 있도록 설계되어 있습니다.

## 소스에서 실행

Python 환경에서 다음 의존성을 설치합니다. OpenCV는 원근 보정과 자동 펴기
등 일부 기하 기능에 사용됩니다.

```powershell
python -m pip install PyQt5 Pillow numpy scipy opencv-python
```

실행 방법:

```powershell
python run.py
python run.py "image.png"
python -m bandwagon
```

Windows에서 콘솔 없이 실행하려면 `run.pyw`를 더블클릭할 수 있습니다.

Ctrl+W는 현재 분석 창을 닫습니다. 저장하지 않은 변경사항이 있으면
저장 여부를 확인하며, 다른 분석 창은 그대로 유지됩니다.

## 개발과 검증

Windows 빌드와 CI의 기준 환경은 CPython 3.14.6 x64입니다.
`requirements-build.lock`은 런타임·빌드 도구와 전이 의존성 버전을 고정합니다.
`build_exe.bat`은 `.venv-build`를 만들고 의존성을 설치·검증한 뒤 빌드합니다.
예상 밖의 패키지가 섞여 있으면 빌드를 중단합니다. 최초 설치에는 인터넷 연결이 필요합니다.
GitHub push/PR 시 `.github/workflows/tests.yml`이 동일한 환경으로 테스트합니다.

## 자동 저장과 복구

열린 분석 창의 저장하지 않은 변경사항은 30초마다 별도 복구 사본으로 저장됩니다.
원래 `.bandwagon` 파일은 Ctrl+S로 저장할 때만 갱신됩니다.
비정상 종료 후 다시 실행하면 사본마다 복구·삭제·나중에 결정 중 선택할 수 있습니다.
복구는 새 창으로 열리며 Ctrl+S로 저장 위치를 선택해야 합니다.
정상 저장 또는 종료(저장 안 함 포함) 시 해당 창의 사본을 삭제합니다.
복구 사본은 Windows의 `%LOCALAPPDATA%/BandWagon/recovery`에 있습니다.
최근 30초 이내 변경과 복구 시점 이전의 되돌리기 이력, 별도 합성 스튜디오의 미내보내기 작업은 복원 대상이 아닙니다.

## 배포 빌드

Windows에서는 PyInstaller로 앱 폴더를 만든 다음 Inno Setup으로 설치 파일을
생성합니다.

```powershell
build_exe.bat
build_installer.bat
```

결과 설치 파일은 `Output/BandWagon_Setup_<version>.exe`에 생성됩니다.
자세한 절차는 [빌드 안내](docs/BUILDING.md#windows)를 참고하세요.

macOS 앱은 실제 macOS 환경에서만 빌드할 수 있습니다.

```bash
./build_mac.sh
```

자세한 내용은 [빌드 안내](docs/BUILDING.md#macos)를 참고하세요.
