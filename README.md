# BandWagon

BandWagon은 젤 전기영동(gel electrophoresis) 이미지에서 레인과 밴드를
검출하고, 분자량(MW)을 계산하며, 분석 결과를 이미지와 CSV로 내보내는
데스크톱 분석 도구입니다. 가시광 이미지와 UV 이미지를 정렬해 합성하는
웨스턴 블롯 작업도 함께 지원합니다.

최신 Windows 설치본과 포터블 버전은
[GitHub Releases](https://github.com/loselessss/BandWagon/releases/latest)에서
받을 수 있습니다.

## 만든 이유

젤 이미지를 분석하려면 이미지 방향과 기울기를 바로잡고, 레인 범위를 정한
뒤, 밴드 위치와 강도를 읽고, 마커를 기준으로 분자량 곡선을 맞춰야 합니다.
이 과정을 여러 프로그램과 수작업으로 나누면 같은 조건으로 다시 분석하기
어렵고 결과를 재현하기도 번거롭습니다.

BandWagon은 이 흐름을 한곳에 모읍니다.

- 젤 이미지의 방향, 기울기, 곡률, 원근을 보정합니다.
- 레인을 자동 검출하거나 직접 추가하고 범위를 조정합니다.
- 밴드를 검출하고 피크 면적과 상대 강도를 계산합니다.
- 분자량 마커를 바탕으로 MW 보정 곡선을 맞춥니다.
- 이미지, 레인, 보정값, 분석 설정과 메모를 프로젝트 하나에 저장합니다.
- 가시광·UV 채널을 별도 스튜디오에서 정렬하고 합성합니다.

## 주요 기능

### 이미지 보정

- 90도 회전, 좌우·상하 반전
- 정밀 회전과 기울기(shear) 보정
- 휘어진 젤의 곡률 보정
- 네 모서리 지정 원근 보정과 자동 펴기
- 밝기, 대비, 채널별 톤 커브 조정
- RGB 및 개별 Red·Green·Blue 채널 분석

### 레인과 밴드 분석

- 레인 자동 검출 및 수동 추가·삭제·정렬
- 레인 이름, 유형, 표시 순서 관리
- 분석 범위와 최소 밴드 간격 조정
- 밴드 민감도와 스미어 허용 범위 조정
- 밴드 경계 영역 또는 피크 선 표시
- 피크 면적, 상대 강도와 분자량 결과 표 제공

### 분자량 보정

- 마커 레인과 기준 분자량 입력
- 사용자 마커 프리셋 저장 및 재사용
- 분자량 커브 피팅과 미지 밴드 MW 계산

### 웨스턴 블롯 합성

- 가시광 이미지와 UV 이미지 불러오기
- 두 채널의 위치·회전·크기 정렬
- 화면용 합성 이미지와 분석용 UV 그레이스케일을 함께 보존
- `.bwcomposite` 파일로 내보낸 뒤 메인 분석 화면에서 불러오기

### 작업 보존과 내보내기

- 이미지와 모든 분석 상태를 `.bandwagon` 프로젝트 하나로 저장
- 이미지·레인·분석 설정·메모를 포함한 최대 200단계 실행 취소/다시 실행
- 사진 포함 여부와 테두리·Marker MW·Annotation(레인 이름)을 선택해 이미지 저장 또는 복사
- 글자와 그림·테두리 투명도, 투명 배경 미리보기, 마지막 내보내기 옵션 기억
- 레인·밴드 결과 CSV 내보내기
- 한국어·영어 UI

[최신 릴리스](https://github.com/loselessss/BandWagon/releases/latest)에서

  포터블 버전

설치본과 포터블 모두 앱 안에서 새 버전을 확인할 수 있습니다. 설치본은 다음
Setup EXE를 받고, 포터블은 다음 Portable ZIP을 받아 기존 폴더를 교체합니다.
포터블 교체 후 새 버전이 정상적으로 시작하지 못하면 이전 폴더를 복구합니다.

## 기본 사용 흐름

1. 젤 이미지를 열거나 클립보드에서 붙여넣습니다.
2. 회전·기울기·곡률·원근과 밝기·대비를 필요한 만큼 보정합니다.
3. 레인을 자동 검출하거나 직접 배치합니다.
4. 마커 레인을 지정하고 기준 분자량을 입력합니다.
5. 밴드 검출 조건을 조정한 뒤 분석을 실행합니다.
6. 결과 이미지와 CSV를 내보내거나 `.bandwagon` 프로젝트로 저장합니다.

가시광·UV 합성이 필요하면 먼저 **웨스턴블롯 → 만들기**에서 합성 파일을
만든 다음, `.bwcomposite`를 메인 분석 화면으로 가져오면 됩니다.

### 화면 조작과 이미지 내보내기

- 앱 전체는 Fluent 스타일의 다크 표면·카드·선형 아이콘·포커스 표시를 사용합니다.
  보정·레인·분석·정량·메모 탭과 복사·마커·웨스턴블롯·업데이트 창에 같은 디자인을 적용했습니다.
  아이콘 버튼은 마우스를 올리면 설명을 표시합니다.
- 상단의 **파일·보정·레인·분석·웨스턴블롯·정보** 작업 탭에서 가로 리본의 아이콘을 선택합니다.
  오른쪽에는 선택한 도구의 설정만 표시하고, 메인 미리보기는 계속 유지합니다. 언어 선택은 정보에 있습니다.
  좁은 창에서 리본이 넘치면 좌우 화살표로 나머지 도구를 볼 수 있습니다.
- **보정** 리본은 회전·뒤집기·자르기·펴기·곡률·기울기·밝기/대비·톤 커브·색상 반전으로 나뉩니다.
  자르기는 사각 영역을 잘라내며, 펴기는 네 모서리 기준 원근을 보정합니다. 영역 지정 후 Enter로 적용합니다.
  가이드는 기하 보정 도구에서만 표시합니다. 도구를 바꾸면 미확정 보정을 적용해 유지하며, Esc/Ctrl+Z로 먼저 취소할 수 있습니다.
- **레인**은 자동 검출·수동 조정·레인 목록·세로 범위·밴드 설정, **분석**은 결과표·정량·메모를 선택합니다.
  웨스턴블롯 만들기도 사진·정렬·합성 설정·내보내기 리본을 사용하며, 미리보기와 내보내기에 같은 UV 겹침 설정을 적용합니다.
- **곡률 펴기**를 누르면 메인 이미지 위에 보라색 손잡이 5개가 나타납니다.
  손잡이를 끄는 방향으로 이미지가 움직이며, 중간 점은 좌우로도 이동해 비대칭 휨을 조절합니다.
  왼쪽 작은 위아래 화살표 손잡이는 곡률 모양을 유지하면서 선 전체를 이동합니다.
  이미지 아래 아이콘 도구 모음에서 초기화·원본 보기·화면 맞춤·도움말·적용·취소를 사용할 수 있습니다.
  눈 아이콘을 누르고 있는 동안 원본을 확인하고, Esc 또는 Ctrl+Z로 미확정 보정을 취소합니다.
  미리보기는 축소본을 사용하고, 적용을 누르면 원본에 반영하며 한 번의 되돌리기로 복원됩니다.
  자동 젤 펴기의 `펴기 후 곡률 손잡이 표시`를 선택하면 이어서 조정할 수 있습니다.
  이 보정은 열마다 같은 세로 이동을 적용합니다. 이미지 높이에 따라 휨이 다르게 변하는
  경우까지 자동으로 추정하지는 않으므로 기준 밴드와 미리보기를 확인하세요.
- 이미지 위 안내에서 현재 마우스 동작을 확인할 수 있으며, Esc로 조정 모드를 종료합니다.
- 레인 이름 편집 중 Enter/Tab은 다음 이름 칸, Shift+Tab은 이전 칸으로 이동합니다.
  Esc는 입력 중인 변경을 취소합니다. 레인 이름이나 표를 선택하면 해당 레인을 강조합니다.
- 레인 자동 검출은 배경 밝기 차이와 진한 밴드의 영향을 줄이고, 예상 간격 근처의 빈 공간 중앙을 찾습니다.
  세로 분석 범위를 지정했다면 그 안의 신호만 사용합니다. 레인 수는 직접 입력하며 경계는 드래그로 수정할 수 있습니다.
- 복사 옵션 등 체크박스는 선택 시 흰색 ✓ 표시가 나타납니다.
- 밴드를 클릭하면 분석 표의 강도 칸으로 이동합니다. 분석 조건을 바꾸면 재분석 안내가 표시됩니다.
  결과 표의 숫자는 오른쪽 정렬되며, 열 너비를 조절하거나 가로로 스크롤할 수 있습니다.
- 복사와 이미지 저장은 같은 옵션 창을 사용합니다. `사진 포함`을 끄면 투명 오버레이만 생성됩니다.
  오버레이는 `테두리`, `Marker MW`, `Annotation(레인 이름)` 중 선택한 요소만 포함합니다.
  일반 레인 MW와 밴드 색칠은 내보내지 않습니다.
- 글자 투명도는 레인 이름과 Marker MW에, 그림·테두리 투명도는 사진과 테두리에 적용됩니다.
  함께 조절을 끄면 각각 설정할 수 있습니다. 0%는 불투명, 100%는 완전 투명입니다.
  미리보기의 체크무늬는 투명 영역이며, 실제 출력은 원본 해상도입니다.

## 파일 형식

- `.bandwagon`: 원본 이미지, 편집 기록, 레인, 분석 설정, 분자량 보정과
  메모를 담는 BandWagon 프로젝트
- `.bwcomposite`: 화면용 합성 PNG와 분석용 UV 그레이스케일 PNG를 함께
  담는 웨스턴 블롯 합성 파일

두 형식 모두 다른 프로그램의 임시 상태에 의존하지 않고 나중에 다시 열어
분석을 이어갈 수 있도록 설계되어 있습니다.

## 소스에서 실행

Python 환경에서 다음 의존성을 설치합니다. OpenCV는 원근 보정과 자동 펴기
등 일부 기하 기능에 사용됩니다.

```powershell
python -m pip install PyQt5 Pillow numpy scipy opencv-python
```

실행 방법:

```powershell
python run.py
python run.py "image.png"
python -m bandwagon
```

Windows에서 콘솔 없이 실행하려면 `run.pyw`를 더블클릭할 수 있습니다.

## 개발과 검증

Windows 빌드와 CI의 기준 환경은 CPython 3.14.6 x64입니다.
`requirements-build.lock`은 런타임·빌드 도구와 전이 의존성 버전을 고정합니다.
`build_exe.bat`은 `.venv-build`를 만들고 의존성을 설치·검증한 뒤 빌드합니다.
예상 밖의 패키지가 섞여 있으면 빌드를 중단합니다. 최초 설치에는 인터넷 연결이 필요합니다.
GitHub push/PR 시 `.github/workflows/tests.yml`이 동일한 환경으로 테스트합니다.

## 자동 저장과 복구

열린 분석 창의 저장하지 않은 변경사항은 30초마다 별도 복구 사본으로 저장됩니다.
원래 `.bandwagon` 파일은 Ctrl+S로 저장할 때만 갱신됩니다.
비정상 종료 후 다시 실행하면 사본마다 복구·삭제·나중에 결정 중 선택할 수 있습니다.
복구는 새 창으로 열리며 Ctrl+S로 저장 위치를 선택해야 합니다.
정상 저장 또는 종료(저장 안 함 포함) 시 해당 창의 사본을 삭제합니다.
복구 사본은 Windows의 `%LOCALAPPDATA%/BandWagon/recovery`에 있습니다.
최근 30초 이내 변경과 복구 시점 이전의 되돌리기 이력, 별도 합성 스튜디오의 미내보내기 작업은 복원 대상이 아닙니다.

## 배포 빌드

Windows에서는 PyInstaller로 앱 폴더를 만든 다음 Inno Setup으로 설치 파일을
생성합니다.

```powershell
build_exe.bat
build_installer.bat
```

결과 설치 파일은 `Output/BandWagon_Setup_<version>.exe`에 생성됩니다.
자세한 절차는 [BUILD_EXE.txt](BUILD_EXE.txt)와
[BUILD_INSTALLER.txt](BUILD_INSTALLER.txt)를 참고하세요.

macOS 앱은 실제 macOS 환경에서만 빌드할 수 있습니다.

```bash
./build_mac.sh
```

자세한 내용은 [BUILD_MAC.txt](BUILD_MAC.txt)를 참고하세요.
